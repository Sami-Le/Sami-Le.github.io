Ministère de l'Intérieur · Laboratoire Digital · 2025-26

Concepteur pédagogique e-learning

Contexte

Le Ministère de l'Intérieur, au sein de sa Sous-direction du Recrutement et de la Formation, dispose d'un Laboratoire Digital chargé de produire des modules e-learning pour les agents de l'État. J'y réalise mon alternance dans le cadre de la Licence professionnelle Innovation Numérique dans l'Édition, avec pour projet de réduire le temps de production manuel de ces modules.

Missions

Conception d'un module

Développement d'un module e-learning interactif sur Storyline 360, à partir d'un storyboard fourni, avec créations graphiques sur Illustrator.

Conception d'un template institutionnel

Création d'un template UX/UI réutilisable sur Storyline 360, respectant la charte visuelle de l'État pour les futurs modules.

Automatisation du flux

Projet d'automatisation transformant storyboard et médias en modules finis via un script Python, en réduisant les tâches manuelles.

Outils utilisés
Storyline 360
Illustrator
Adapt Learning
Python
JSON / XML
